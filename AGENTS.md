# Repository Working Rules

## Vertical-task commit rule

- Treat each independently testable vertical task as a separate unit of work.
- As soon as a vertical task is complete and verified, commit it immediately.
- Every commit message must be written in English.
- Do not combine multiple completed vertical tasks into one commit.
- Do not begin the next vertical task while completed work remains uncommitted.
- Never include unrelated or pre-existing user changes in these commits.
