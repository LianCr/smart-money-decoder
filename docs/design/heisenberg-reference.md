# heisenberg.so 视觉逆向笔记（2026-10-30）

只借视觉语言（令牌、版式、组件形态），**不搬**对方的名字、logo、文案、插图。SMD 保留自己的品牌和文字。

## 整体气质
浅色、冷灰白、大量留白，像一份安静的研究报告；数字和标签用等宽字，正文用系统无衬线。
"强调"靠一抹钢蓝和深海军蓝实心按钮，几乎没有阴影和发光。

## 字体
- 无衬线：`ui-sans-serif, system-ui`（Mac 上即 SF Pro）——267 个元素
- 等宽：**Spline Sans Mono**（Google Fonts）——73 个元素：钱包地址、价格大数字、ROI、表头、eyebrow、tabs
- h1 68px **w300**，字距 -2.38px（约 -0.035em）；h2 38px w300 字距 -0.03em；h3 19px w500
- 段落 20px/30px；正文 16px
- eyebrow / 区块标签：等宽 10.5–11.5px，全大写，字距约 0.16em，灰或钢蓝

## 版式与组件
- 顶栏：白底半透明 + 底部 1px 分隔线，固定；左 logo，右侧文字链接 + 深色实心按钮
- Hero：居中，eyebrow → 超大细体标题（最后一个关键词钢蓝）→ 灰色副标题 → 一个主按钮 → 小字备选
- 主演示：一个"终端窗"大卡，左右两栏：左边市场标题 + 等宽大价格 + 面积折线图（钢蓝 1.5px 线，淡渐变填充），右边分层条 + 小卡列表 + 一句结论
- 三列特性卡：标题 19px + 灰色正文，无图标
- 指标条：一行等宽小字，中间用 · 圆点分隔
- 胶囊 tabs：等宽 13px，白底 1px 边框，圆角 12px；选中 = 深海军蓝实心白字（点击即切数据，无动画）
- 数据表：表头等宽 10.5px 全大写灰；行高宽松（~74px），行间 1px 分隔；数字绿色 + 下方灰色小字解释样本量；表底一行灰字注明口径
- 页脚：深海军蓝整块，四列等宽小标题链接 + 免责声明小字

## 交互观察
- 按钮 hover 只是微微变亮，没有位移
- tab 切换即时刷新表格数据
- 整页无动画炫技，只有 logo 跑马灯在动

## 映射到 SMD
- 00-base.css 令牌从深色终端改为上面的浅色系；`--accent` → 钢蓝，实心按钮 → 海军蓝
- `--mono` → Spline Sans Mono；`--sans` → 系统无衬线；大标题改 w300 + 负字距
- 盈亏绿红改成 #2f7a55 / #c0392b 这一档的沉稳色；党派色保留但调成浅底可读的蓝/砖红
- 卡片统一白底 1px 边 + 13px 圆角，去掉发光；推荐/看板主卡用"终端窗"样式
- 区块标题改成等宽全大写 eyebrow
